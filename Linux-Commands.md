# Linux Commands

A collection of basic Linux commands and their uses.

## 1. sudo su
Switches to the root (superuser) account.

## 2. sudo
Runs a command with elevated privileges.

## 3. pwd
Shows the current working directory.

## 4. ls
Lists files and directories.

## 5. cd
Changes the current directory.

## 6. mkdir
Creates a new directory.

## 7. touch
Creates a new empty file.

## 8. cat
Displays the contents of a file.

## 9. vi
Opens a file in the Vi text editor.

## 10. nano
Opens a file in the Nano text editor.

## 11. rm
Removes files or directories.

## 12. cp
Copies files or directories.

## 13. mv
Moves or renames files and directories.

## 14. grep
Searches for specific text or patterns in files.

## 15. find
Searches for files and directories.

## 16. file
Shows the type of a file.

## 17. echo
Displays text or variables in the terminal.

## 18. clear
Clears the terminal screen.

## 19. whoami
Shows the current logged-in user.

## 20. history
Shows previously executed commands.

## 21. man
Displays the manual/help page for a command.

## 22. head
Displays the first few lines of a file.

## 23. tail
Displays the last few lines of a file.

## 24. chmod
Changes file or directory permissions.

## 25. chown
Changes the owner of a file or directory.
